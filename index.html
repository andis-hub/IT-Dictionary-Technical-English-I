Operating Systems

What is an Operating System?

An Operating System (OS) is a set of software programs that lies between application software and the computer hardware. Without an OS, a brand-new computer cannot perform any task.

Conceptual Layers of an OS

System Architecture Layers (From user to machine):

  1. User: The person interacting with the computer.
  2. Applications Programs: Software used to perform tasks (e.g., word processing, payroll, games).
  3. Operating System: Software interface managing system resources and hardware interaction.
  4. Hardware: Physical components (CPU, Memory, Disks, Input/Output devices).

Key Concepts & Functions

Supervisor Program

Programa supervisor

Definition: The most important OS program that manages the system, controls operations, and loads other programs into memory.

Example: Most of the supervisor program remains in memory while the system is running.

Resident vs. Non-Resident

Residente vs. No Residente

Definition: Resident programs remain constantly in memory. Non-resident programs are loaded from disk only when needed.

Example: The supervisor is resident, whereas secondary utilities are non-resident.

Command-Line Interface (CLI)

Interfaz de línea de comandos

Definition: Text-based interface where users type explicit commands (e.g., Unix commands like date, ls, passwd).

Example: MS-DOS and early Unix systems relied heavily on CLI environments.

Graphical User Interface (GUI)

Interfaz gráfica de usuario

Definition: Visual interface using icons, windows, menus, and a pointer for interaction.

Example: GUIs replace typed commands with visual interactions using a mouse.

Memory & Process Management

Gestión de memoria y procesos

Definition: The OS allocates RAM, handles Virtual Memory when RAM is full, and schedules CPU time across processes.

Example: Efficient multitasking requires the OS scheduler to manage CPU usage.

File Systems & Paths

Sistemas de archivos y rutas

Definition: Structured rules for storing data (e.g., NTFS for Windows, ext4 for Linux, APFS for macOS).

Example: Windows uses backslashes (C:\), while Unix/Linux systems use forward slashes (/home/user).

Language Work: -ing form as a Noun (Gerunds)

In Technical English, the -ing form of a verb can function as a noun (subject or object) or follow a preposition to describe OS operations:

Examples from Technical Texts:

  • Managing the computer's resources is an important function of the operating system.
  • The OS starts running the user interface as soon as the PC is switched on.
  • Don't switch off without closing down your PC.
  • You can find information on the Internet by using a search engine.

Operating Systems Overview

OS / Architecture File System Interface Type Key Characteristics
Windows NTFS / FAT32 GUI / PowerShell Dominates desktop PCs; uses drive letters (C:\) and Registry configuration.
Linux / Unix ext4 CLI (Terminal) / GUI Open-source, highly stable; powers servers and educational hardware (Plan Ceibal).
macOS APFS GUI / Terminal Optimized for Apple SSD hardware; uses mounting points (/Volumes/).

E-Mail

What is an E-Mail?

An e-mail is an electronic message sent from one person to another using the internet.

Structure of an E-Mail

1. Subject: The main topic of the message.

2. Greeting: A polite way to start the message.

3. Introduction: Explain the reason for writing.

4. Body: Include the main information.

5. Closing: End the message politely.

6. Signature: Include your name.

Example of an E-Mail

To: teacher@example.com

Subject: English Assignment

Dear Teacher,

I am writing to ask about the English assignment. Could you please explain the instructions?

Thank you for your time.

Best regards,

Andis Peña

Reported Speech

What is Reported Speech?

Reported Speech is used to tell someone what another person said without repeating their exact words.

Direct Speech

Direct Speech repeats the exact words spoken by a person.

Example:

She said, "I am studying English."

Reported Speech

Reported Speech communicates the same information without using the speaker's exact words.

Example:

She said that she was studying English.

Examples

  • Direct: He said, "I am tired."
    Reported: He said that he was tired.
  • Direct: She said, "I like computers."
    Reported: She said that she liked computers.
  • Direct: They said, "We are working."
    Reported: They said that they were working.
  • Direct: He said, "I will study."
    Reported: He said that he would study.

Collocations

What are Collocations?

Collocations are combinations of words that are commonly used together in English. They sound natural to native speakers.

Common Collocations

Make a decision

Tomar una decisión

Example: We need to make a decision today.

Do homework

Hacer los deberes

Example: I have to do my homework.

Take a break

Tomar un descanso

Example: Let's take a break after studying.

Pay attention

Prestar atención

Example: Please pay attention in class.

Make progress

Progresar

Example: She is making progress in English.

Save time

Ahorrar tiempo

Example: This application helps us save time.

Keep in touch

Mantenerse en contacto

Example: We keep in touch by e-mail.

Make sure

Asegurarse

Example: Make sure the computer is turned off.

Logics

What is Logic?

Logic is the study of correct reasoning. It helps us analyze information, identify relationships and reach conclusions.

Types of Reasoning

Deductive Reasoning

Deductive reasoning starts with general information and reaches a specific conclusion.

Example:

All humans are mortal.

Socrates is human.

Therefore, Socrates is mortal.

Inductive Reasoning

Inductive reasoning uses specific observations to form a general conclusion.

Example:

The sun has risen every morning.

Therefore, the sun will probably rise tomorrow.

Important Concepts

  • Premise: A statement that supports an argument.
  • Conclusion: A result reached through reasoning.
  • Validity: The logical structure of an argument.
  • Soundness: An argument that is valid and has true premises.
  • Evidence: Information used to support a statement.
